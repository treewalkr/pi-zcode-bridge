# AGENTS.md

## Commits

- **Commit often** — small, frequent commits after each meaningful unit of work.
- **Short message** with a prefix, e.g. `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, `test:`.
  - Example: `fix: guard balance check before turn`
- **No body** — subject line only.
- **No co-author** — never append `Co-Authored-By` trailers.
